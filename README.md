# 📚 School Management App

This is a Java-based Android application designed for managing student information and streamlining communication between students and administrators.

 🚀 Features

### Admin Panel
- Add student profiles
- Send notices to students
- View/respond to student queries
- Approve/reject leave applications
- Login/logout

### Student Panel
- View profile
- Read notices
- Check attendance and holidays
- Apply for leave
- Submit queries to admin
- Login/logout
